Choose a password

This meter is still using the password it shipped with. That password is printed in the manual and published in the source code, so anyone on this network can currently read your data, change your settings, and install firmware on it.

Until you set your own password, the meter will not serve anything else.

Your browser will ask you to sign in again with the new password. The username stays admin.

Reached this over the meter's own WiFi because it lost your network? Reconnect it first.
