LED

LED brightness is used to adjust the brightness of the status LED on the device. Keeping a small amount of brightness is recommended.

 

Disco mode runs a short burst of colours on the status LED, then hands it back to the device. Handy to confirm you are looking at the right meter.

Logging

Logging is used to record events and errors. It is useful for debugging and troubleshooting.

Print

Print logging is used to display events and errors when the serial monitor is available. The serial monitor is available when the device is connected to a computer via USB.


Save

Save logging is used to record events and errors to the internal memory of the device. The internal memory is limited, so it is recommended to only use this for troubleshooting.

After restart the device checks the static IP. If it can't reach the internet, it reboots once back into automatic (DHCP) so the device stays reachable. A separate boot-failure safeguard also reverts to DHCP if the device can't start on the static IP - that one is always on.
⚠️ Warning - auto-recovery is off. If this static IP is wrong or conflicts with another device, the device may become unreachable and you would have to recover it through the WiFi setup portal. Keep auto-recovery on unless you are sure the address is correct.

Switch WiFi Network

Enter new WiFi credentials to switch to a different network. The device will save the credentials and restart to connect to the new network.

⚠️ Warning: The device will restart to apply the new credentials. You will temporarily lose access.

Disconnect from WiFi

This will erase the WiFi credentials.

The device will create a password-protected WiFi network called "EnergyMe-XXXXXXXXXX" (where XXXXXXXXXX is the device ID). The password is printed on the device. Connect to that network and navigate to http://172.31.42.1 if the device does not redirect you automatically. You can then configure the device to connect to your WiFi network.

⚠️ Warning: You will lose access to the device until you reconnect it to WiFi.

Factory Reset

This will reset the device to its factory settings. Useful if you are having issues with the device or want to start fresh.

⚠️ Warning: This will erase all configurations, data, and WiFi credentials. This action cannot be undone.

✅ Factory reset done - reconnect the device

This device has left your WiFi network and is now waiting to be set up again. It is no longer reachable at this address.

  1. Wait about 30 seconds for the device to finish restarting.
  2. On your phone or laptop, join the WiFi network EnergyMe-<device id>.
  3. The setup page should open by itself. If it does not, open http://172.31.42.1 in a browser.
  4. Pick your WiFi network there and enter its password.

The LED blinks blue quickly while the device is waiting to be set up.
